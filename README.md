# HomeNet

HomeNet 是一个基于 Tauri 的本地网络管理工具，前端使用 React + TypeScript 实现。

## 界面与菜单栏

- 顶部标签切换总览、设备与 DDNS、端口转发、反向代理、文件服务和日志，右上角进入偏好设置。
- 默认使用石墨深色，也可选择柔和浅色或跟随系统；主窗口与状态小窗同步主题。
- 单击系统菜单栏 / 托盘图标，展开当前状态小窗：网络地址、启用规则数、服务状态和最近日志。
- 菜单栏与应用内标题栏使用无边框连接节点图标，macOS 自动适配系统深浅外观；右键保留“查看当前状态 / 打开 HomeNet / 退出”菜单。
- Dock、启动台和安装包的程序图标使用独立的圆角细框连接节点图案，不与菜单栏图标混用。
- 小窗显示时每 15 秒刷新，隐藏后停止轮询；可手动刷新、复制地址，或点击服务跳转主窗口。
- 再次单击图标、点击外部或按 Esc 收起小窗。关闭主窗口不停止服务；小窗或托盘菜单中的“退出”会结束应用和网络服务。
- Windows 保留双击托盘打开主窗口；Linux 托盘不支持点击事件时，可通过菜单中的“查看当前状态”打开小窗。

浏览器 `pnpm dev` 仅展示界面，真实状态和菜单栏交互需要 `pnpm tauri dev`。直接访问 `/?view=tray` 可检查状态小窗的布局；没有 Tauri 后端时会明确显示读取失败，不会填充模拟状态。

程序图标源文件为 `src-tauri/icons/app-icon.svg`，运行 `pnpm icons:app` 生成桌面平台的 PNG、ICNS 和 ICO，运行 `pnpm icons:check` 检查生成资源是否一致。菜单栏图标独立保存在 `tray-icon.svg`，通过 `python3 scripts/generate-tray-icon.py` 生成，应用内仍直接使用无框的 Waypoints 图标。

## 设备与 DDNS

- 主页面的“DDNS 设备”只显示已添加绑定的设备，包括停用和离线设备；同设备多条绑定合并为一行，解除最后一条绑定后从此列表移除。完整局域网设备清单仅在“新增绑定”的设备选择弹层中显示，列表筛选不会裁剪共享发现缓存。
- 点击“新增绑定”，可选择已发现设备，或按 MAC 地址手动添加尚未发现的设备。手动添加不绕过本地网络权限，设备被发现并获得可用地址后才会自动同步。
- 设备选择使用应用内搜索弹层，列出全部发现设备及已绑定离线设备，支持名称、IP、MAC 搜索、键盘选择和手动刷新；打开弹层不会重新扫描。
- 弹层内刷新会保持列表、搜索词及当前选择，不因鼠标点击或加载时焦点变化而收起。重复点击会复用正在进行的刷新。
- macOS / Windows 的设备列表扫描会按网卡实际子网掩码主动触发 IPv4 邻居发现，不再只依赖已有邻居缓存。仅探测直连私有 / 链路本地网段，每轮最多 1024 个地址，大网段分批轮询；仍受本地网络权限、设备休眠和路由器隔离影响，不能保证发现不可达设备。
- macOS 的 IPv4 探测绑定活动局域网网卡，辅助广播使用各网卡的子网广播地址，不再发送到可能被 VPN 接管的全局广播地址。路由不可达与权限拒绝分别提示；辅助广播失败仍继续其他发现路径，同一错误不会逐轮重复刷日志。
- macOS 还会校验 ICMP Echo 回包：即使系统不提供 ARP/MAC 信息，确实响应的设备也按 IP 显示，不会仅凭发送成功就标记在线。不响应探测的设备仍可能无法发现；IP-only 设备不能凭历史 IP 自动匹配 DDNS 绑定。
- macOS 的 MAC 读取在 HomeNet 进程内通过标准 `sysctl` 邻居表和 `getifaddrs` 网卡接口完成，不再只依赖 `arp` / `ndp` / `ifconfig` 子进程。仍遵守系统访问权限；空表、隐藏 MAC 或不完整记录不会被伪造为可绑定设备。日志区分原生读取与命令读取的有效记录数。
- 设备发现日志记录每个网卡的目标数、发送数、原始回包数、有效设备数与错误数，以及最终扫描数量；这些统计不包含凭据或回包内容，可用于区分安装版的权限/网络问题与回包校验问题。
- `02:00:00:00:00:00` 属于系统隐藏硬件地址时使用的占位值，不作为设备身份，也不允许新建绑定；已有绑定如果保存了此占位值，需修正为真实 MAC 后再同步。MAC 不可读取时，列表保留可达设备并明确提示限制；手动绑定需填写真实 MAC，自动同步仍须验证设备身份。
- 同一设备支持多个不同域名或不同记录类型；在设备详情中选择具体绑定后编辑或解除，不影响该设备的其他绑定。
- 设备数据在应用启动时加载，之后每 60 秒定时刷新；切换页面、打开绑定编辑器不会重新扫描，也可手动刷新。
- 扫描期间及读取失败时保留已有列表。已绑定但扫描不到的设备仍显示为离线，可查看、编辑或解除绑定；上次地址不会被当成当前可用的同步地址。
- 本次运行中曾发现的其他局域网设备会保留在“新增绑定”的候选列表中，未再次发现时标记离线；不会因此进入主页面的“DDNS 设备”列表。
- 历史配置中相同服务商、完整域名和记录类型的重复绑定统一保留最后写入的一条；新增时遇到相同记录则提示冲突，不覆盖已有配置。
- macOS 15 及以上版本需要允许 HomeNet 访问本地网络。若只能发现本机，请在「系统设置 → 隐私与安全性 → 本地网络」检查 HomeNet 权限，然后手动刷新；终端能读取邻居表不代表应用已获得权限。应用包包含本地网络用途说明，但不会自动更改系统授权。

## 检查更新

未配置更新签名的构建在 GitHub 版本接口受限或不可用时，会回退到本仓库的官方发布页确认版本，并核实对应平台的安装包存在。两种方式都失败时会明确报错，不会误报“已是最新版本”，也不需要用户提供 GitHub Token。

安装仍需用户确认，并在安装前重新检查版本。已配置签名的构建继续走签名验证流程，不会降级为未签名更新；安装包来源限于 HomeNet 官方 HTTPS 发布地址。

## WebDAV 服务

HomeNet 可以把一个本地目录作为 WebDAV 服务共享，并支持：

- 自定义监听地址和端口，默认仅监听 `127.0.0.1:19080`。
- 多账号、账号启停和独立的只读/读写权限。
- 全局只读模式、WebDAV 文件锁和服务运行状态检测。
- 密码使用 Argon2id 加盐哈希保存，不会在界面或 IPC 中回显。

WebDAV 使用 Basic Auth。通过公网访问时，请保持 WebDAV 仅监听本机，并使用 HomeNet 的 HTTPS 反向代理提供加密入口；不要直接把未加密的 WebDAV HTTP 端口暴露到公网。

## macOS 安装提示

macOS 构建会对整个应用包执行 ad hoc 签名，签名标识使用固定的 `com.nowat.homenet`，CI 在发布前校验资源封印及签名。它不等同于 Developer ID 签名或 Apple 公证，也不保证系统授权跨更新保留；签名校验通过不代表已取得本地网络权限。调试包可用 `pnpm verify:macos-bundle` 验证。

如果 macOS 提示应用来自未知开发者，或下载后的应用被系统隔离，可以在安装到 `/Applications` 后执行：

```bash
sudo xattr -dr com.apple.quarantine /Applications/HomeNet.app
```

# HomeNet

HomeNet 是一个基于 Tauri 的本地网络管理工具，前端使用 React + TypeScript 实现。

## 界面与菜单栏

- 顶部标签切换总览、设备与 DDNS、端口转发、反向代理、文件服务和日志，右上角进入偏好设置。
- 默认使用石墨深色，也可选择柔和浅色或跟随系统；主窗口与状态小窗同步主题。
- 单击系统菜单栏 / 托盘图标，展开当前状态小窗：网络地址、启用规则数、服务状态和最近日志。
- 菜单栏使用与标题栏一致的连接节点图标，macOS 自动适配系统深浅外观；右键保留“查看当前状态 / 打开 HomeNet / 退出”菜单。
- 小窗显示时每 15 秒刷新，隐藏后停止轮询；可手动刷新、复制地址，或点击服务跳转主窗口。
- 再次单击图标、点击外部或按 Esc 收起小窗。关闭主窗口不停止服务；小窗或托盘菜单中的“退出”会结束应用和网络服务。
- Windows 保留双击托盘打开主窗口；Linux 托盘不支持点击事件时，可通过菜单中的“查看当前状态”打开小窗。

浏览器 `pnpm dev` 仅展示界面，真实状态和菜单栏交互需要 `pnpm tauri dev`。直接访问 `/?view=tray` 可检查状态小窗的布局；没有 Tauri 后端时会明确显示读取失败，不会填充模拟状态。

## 设备与 DDNS

- 设备数据在应用启动时加载，之后每 60 秒定时刷新；切换页面、打开绑定编辑器不会重新扫描，也可手动刷新。
- 扫描期间及读取失败时保留已有列表。已绑定但扫描不到的设备仍显示为离线，可查看、编辑或解除绑定；上次地址不会被当成当前可用的同步地址。
- 本次运行中曾发现的其他设备会保留在列表中，未再次发现时标记离线。
- 相同服务商、完整域名和记录类型的重复绑定统一保留最后写入的一条，避免更换网卡后重复计数或重复同步。
- macOS 15 及以上版本需要允许 HomeNet 访问本地网络。若只能发现本机，请在「系统设置 → 隐私与安全性 → 本地网络」检查 HomeNet 权限，然后手动刷新；终端能读取邻居表不代表应用已获得权限。应用包包含本地网络用途说明，但不会自动更改系统授权。

## WebDAV 服务

HomeNet 可以把一个本地目录作为 WebDAV 服务共享，并支持：

- 自定义监听地址和端口，默认仅监听 `127.0.0.1:19080`。
- 多账号、账号启停和独立的只读/读写权限。
- 全局只读模式、WebDAV 文件锁和服务运行状态检测。
- 密码使用 Argon2id 加盐哈希保存，不会在界面或 IPC 中回显。

WebDAV 使用 Basic Auth。通过公网访问时，请保持 WebDAV 仅监听本机，并使用 HomeNet 的 HTTPS 反向代理提供加密入口；不要直接把未加密的 WebDAV HTTP 端口暴露到公网。

## macOS 安装提示

如果 macOS 提示应用来自未知开发者，或下载后的应用被系统隔离，可以在安装到 `/Applications` 后执行：

```bash
sudo xattr -dr com.apple.quarantine /Applications/HomeNet.app
```
